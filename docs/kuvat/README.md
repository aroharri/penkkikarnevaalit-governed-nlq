# Kuvakaappaukset

Pudota kuvat tähän kansioon näillä nimillä. README:ssä on valmiit kohdat
merkittynä `<!-- KUVA: ... -->` — poista kommenttimerkit, niin kuva ilmestyy.

Kunnes kuva on olemassa, sen paikka on kommentoituna. Rikkinäinen kuvake
README:ssä näyttää huolimattomalta, joten mikään ei osoita tiedostoon, jota
ei ole.

| Tiedosto | Mitä siinä pitäisi näkyä |
|---|---|
| `answer.png` | Vastaus lähdeviitteineen: luku, sen alla mitattu/laskennallinen -jako, ja `- Lahde` -lohko kokonaisuudessaan. **Tämä on tärkein kuva** — se näyttää yhdellä silmäyksellä, että luku tulee nimetystä mittarista ja tunnetulla rajauksella. |
| `clarify.png` | Tarkennuspyyntö: `Mika on tavoite?` ja kaksi kilpailevaa tavoitelukua vaihtoehtoina. Tämä on se, mitä tavallinen kyselybotti ei tee. |
| `refuse.png` | Kieltäytyminen: `Mika on Kallen nykyinen ykkosmaksimi?` ja selitys siitä, että hän on datassa mutta ei haasteessa. Mukaan rivi *"En palauta nollaa enka tyhjaa taulukkoa"*. |
| `menu.png` | `:menu` — ruokalista siitä mitä voi kysyä. Vapaaehtoinen, mutta se vastaa kysymykseen "mitä minä tälle sanon". |

## Ohjeet kuvaajalle

Aja `kysy.cmd`, kysy kysymys, ota kuva Windowsin leikkaustyökalulla
(`Win + Shift + S`).

Muutama asia, jotka tekevät kuvasta paremman:

- **Ota koko vastaus mukaan, myös `- Lahde` -lohko.** Ilman sitä kuva näyttää
  chatbotilta. Lähdeviite on koko juttu.
- **Leikkaa vasen reuna tiukasti.** Terminaali-ikkunan reunat eivät kerro mitään.
- **Älä suurenna fonttia jälkikäteen.** Suurenna terminaalin fonttia ennen
  kuvaa (`Ctrl + rullahiiri`), niin teksti pysyy terävänä.
- Tummalla taustalla kuva näyttää GitHubissa hyvältä sekä vaaleassa että
  tummassa teemassa.
